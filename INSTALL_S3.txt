  ВАЖНО: УСТАНОВКА ЗАВИСИМОСТЕЙ ДЛЯ РАБОТЫ С S3
═══════════════════════════════════════════════════════════

Код обновлён для загрузки файлов в Timeweb S3.
Перед запуском приложения выполните:

  npm install

Это установит необходимые пакеты:
  • @aws-sdk/client-s3 (для работы с S3)
  • @supabase/supabase-js (опционально)

После установки перезапустите dev-сервер:

  npm run dev

═══════════════════════════════════════════════════════════

Проверьте, что в .env настроены переменные S3:
  ✓ S3_ACCESS_KEY_ID
  ✓ S3_SECRET_ACCESS_KEY
  ✓ S3_BUCKET_NAME
  ✓ S3_REGION
  ✓ S3_ENDPOINT

Подробности в файле: STORAGE_S3_SETUP.md
