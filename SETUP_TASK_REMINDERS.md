# 🔔 Настройка напоминаний о просроченных задачах

## ✅ Что реализовано:

### 1. **Автоматические напоминания через Telegram**
- ⏰ За 3 часа до конца рабочего дня (15:00 при окончании в 18:00)
- ⏰ За 1 час до конца рабочего дня (17:00 при окончании в 18:00)
- 🌍 Учет часового пояса каждого объекта
- 📱 Отправка даже когда пользователь не в системе

### 2. **Поддержка часовых поясов**
- Определение по городу объекта
- Рабочие часы по умолчанию: 9:00 - 18:00
- Настройка для каждого объекта отдельно

### 3. **Vercel Cron Jobs**
- Автоматическая проверка каждый час
- Работает независимо от пользователей
- Надежно и бесплатно

## 📋 Шаги для запуска:

### Шаг 1: Применить миграцию базы данных

```bash
npx prisma db push
npx prisma generate
```

**Что добавляется:**
- `workStartTime` - время начала рабочего дня (по умолчанию "09:00")
- `workEndTime` - время окончания рабочего дня (по умолчанию "18:00")
- `city` - город для определения часового пояса
- `timezone` - часовой пояс (по умолчанию "Europe/Moscow")

### Шаг 2: Добавить переменную окружения

В файл `.env` добавьте:

```env
CRON_SECRET=your_random_secret_string_here
```

**Как сгенерировать:**
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### Шаг 3: Настроить Vercel Cron Jobs

**Локально (для тестирования):**

Cron не работает локально, но можно вызвать endpoint вручную:

```bash
curl http://localhost:3000/api/cron/check-overdue-tasks \
  -H "Authorization: Bearer your_cron_secret_here"
```

**На Vercel:**

1. Файл `vercel.json` уже создан с конфигурацией
2. При деплое Vercel автоматически настроит cron
3. Добавьте `CRON_SECRET` в Environment Variables на Vercel

### Шаг 4: Перезапустить сервер

```bash
npm run dev
```

## 🔧 Расписание cron

### Текущее:
```
0 * * * *  // Каждый час
```

**Как это работает:**
- Проверка запускается в начале каждого часа (00 минут)
- Для каждого объекта определяется местное время
- Если местное время = 15:00 или 17:00, отправляется напоминание
- Благодаря часовым поясам, каждый объект получает напоминание в своё время

### Альтернативные варианты:

**Каждые 30 минут:**
```
*/30 * * * *
```

**Только в рабочие часы (9-18 по UTC):**
```
0 9-18 * * *
```

## ⚠️ Важные замечания

### 1. **Browser Notifications НЕ ИСПОЛЬЗУЮТСЯ**

Они не подходят для этой задачи, так как:
- ❌ Работают только когда браузер открыт
- ❌ Не работают когда пользователь не в системе

**Используется только Telegram!**

### 2. **Менеджер должен привязать Telegram**

Без привязки уведомления не придут:
1. Откройте `/telegram`
2. Нажмите "Привязать Telegram"
3. Отправьте `/bind КОД` боту

### 3. **Vercel Cron Jobs - бесплатно**

На Hobby плане Vercel:
- ✅ До 2 cron jobs бесплатно
- ✅ Неограниченное количество выполнений
- ✅ Надежность 99.9%

### 4. **Часовые пояса определяются автоматически**

При создании объекта:
- Укажите город в поле `city`
- Система автоматически определит timezone
- Можно изменить вручную если нужно

## 🆘 Troubleshooting

### Уведомления не приходят:

1. **Проверьте логи cron:**
   - На Vercel: Cron Jobs → Logs
   - Локально: консоль сервера

2. **Проверьте привязку Telegram:**
   - Менеджер должен привязать Telegram
   - Проверьте поле `telegramId` в базе

3. **Проверьте рабочие часы:**
   - Убедитесь что `workEndTime` установлен
   - Проверьте часовой пояс объекта

4. **Проверьте наличие незакрытых задач:**
   - Должны быть задачи со статусом != COMPLETED
   - Задачи должны быть на сегодня

### Cron не запускается:

1. **Проверьте vercel.json:**
   - Файл должен быть в корне проекта
   - Синтаксис должен быть правильным

2. **Проверьте деплой:**
   - Cron работает только на production
   - Локально нужно вызывать вручную

3. **Проверьте CRON_SECRET:**
   - Должен быть установлен в Vercel
   - Должен совпадать с тем, что в коде
