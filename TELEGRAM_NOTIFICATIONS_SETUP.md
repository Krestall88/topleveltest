# 📱 Telegram Уведомления - Инструкция по настройке

## ✅ Что уже сделано

### 1. **Сервис уведомлений** (`src/lib/telegram-notifications.ts`)
Создан сервис для отправки различных типов уведомлений:
- ✉️ Уведомление о новой задаче
- 🏢 Уведомление о назначении на объект
- 🗺️ Уведомление о назначении на участок
- ⏰ Уведомление о просроченной задаче
- 💬 Уведомление о комментарии к задаче
- 🔄 Уведомление о смене роли

### 2. **API для привязки** (`src/app/api/user/telegram/bind/route.ts`)
- `POST /api/user/telegram/bind` - генерация кода привязки
- `GET /api/user/telegram/bind` - проверка статуса привязки
- `DELETE /api/user/telegram/bind` - отвязка Telegram

### 3. **Webhook обработчик** (`src/app/api/webhooks/telegram/route.ts`)
- Обработка команды `/bind CODE` для привязки менеджера
- Автоматическая отправка уведомлений при создании задач

### 4. **UI компоненты**
- `src/components/TelegramBindingWidget.tsx` - виджет привязки Telegram
- `src/app/user-settings/page.tsx` - страница настроек пользователя

### 5. **Интеграция уведомлений**
Уведомления интегрированы в:
- ✅ Создание дополнительных задач из Telegram
- ✅ Назначение менеджера на объект
- ✅ Назначение менеджера/старшего менеджера на участок

### 6. **Схема базы данных** (`prisma/schema.prisma`)
Добавлены поля в модель `User`:
```prisma
telegramId               String?                 @unique
telegramUsername         String?
telegramFirstName        String?
telegramLastName         String?
```

Добавлена модель `TelegramBindingCode`:
```prisma
model TelegramBindingCode {
  id        String   @id @default(cuid())
  createdAt DateTime @default(now())
  code      String   @unique
  userId    String   @unique
  expiresAt DateTime
  user      User     @relation("TelegramBindingCodes", fields: [userId], references: [id], onDelete: Cascade)
}
```

## 🔧 Что нужно сделать для запуска

### Шаг 1: Применить миграцию базы данных

**⚠️ ВАЖНО: Перед выполнением убедитесь, что у вас есть резервная копия базы данных!**

Выполните команду:
```bash
npx prisma db push
```

Эта команда добавит новые поля в таблицу `User` и создаст таблицу `TelegramBindingCode` без потери данных.

### Шаг 2: Обновить Prisma Client

После применения миграции обновите Prisma Client:
```bash
npx prisma generate
```

### Шаг 3: Перезапустить сервер разработки

Перезапустите dev сервер, чтобы изменения вступили в силу:
```bash
npm run dev
```

### Шаг 4: Добавить переменные окружения

**Добавьте в файл `.env` следующие строки:**

```env
# Username вашего бота (БЕЗ символа @)
# Чтобы узнать: откройте бота в Telegram и посмотрите username
TELEGRAM_BOT_USERNAME=your_bot_username

# URL вашего приложения (для ссылок в уведомлениях)
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

**Как узнать username бота:**
1. Откройте вашего бота в Telegram
2. Посмотрите username в шапке чата (например: `@my_cleaning_bot`)
3. Укажите БЕЗ символа `@` (например: `my_cleaning_bot`)

**Важно:** Токен `TELEGRAM_BOT_TOKEN` у вас уже есть - используйте тот же самый бот!

## 📖 Как использовать

### Для менеджеров:

1. **Перейти в настройки**
   - Откройте страницу `/user-settings`

2. **Привязать Telegram**
   - Нажмите кнопку "Привязать Telegram"
   - Скопируйте код привязки
   - Откройте бота в Telegram
   - Отправьте команду `/bind КОД`
   - Дождитесь подтверждения

3. **Получать уведомления**
   - После привязки вы будете автоматически получать уведомления о:
     - Новых задачах
     - Назначении на объекты
     - Назначении на участки
     - И других событиях

### Для администраторов:

1. **Ссылка на настройки уже добавлена в меню**
   - ✅ Пункт "👤 Профиль и уведомления" доступен всем пользователям в главном меню
   - Находится перед кнопкой "Выход"

2. **Мониторинг**
   - Проверяйте логи сервера для отслеживания отправки уведомлений
   - Логи содержат информацию о успешной/неуспешной отправке

## 🔍 Отладка

### Проверка ошибок TypeScript

Все ошибки TypeScript, связанные с `telegramId` и `telegramBindingCode`, исчезнут после выполнения `npx prisma generate`.

### Проверка работы уведомлений

1. Привяжите свой Telegram аккаунт
2. Попросите кого-то назначить вас на объект
3. Проверьте, пришло ли уведомление в Telegram

### Логи

Все уведомления логируются в консоль:
- `✅ Telegram сообщение отправлено: {telegramId}`
- `📱 Уведомление отправлено менеджеру: {name}`

## ⚠️ Важные замечания

1. **Коды привязки** действительны 15 минут
2. **Один Telegram** может быть привязан только к одному аккаунту
3. **Один аккаунт** может иметь только один привязанный Telegram
4. **Уведомления** отправляются только если у пользователя привязан Telegram
5. **Ошибки отправки** логируются, но не блокируют основной функционал
