## 💡 Рекомендации:

### Для быстрой адаптации:

1. **Используйте готовые классы:**
   ```tsx
   <div className="responsive-container">
     <h1 className="mobile-text-xl">Заголовок</h1>
     <Button className="mobile-button-sm flex-1 sm:flex-none">
       <Icon className="mobile-icon" />
       <span className="hide-mobile">Полный текст</span>
       <span className="show-mobile">Короткий</span>
     </Button>
   </div>
   ```

2. **Проверяйте на iPhone SE (375px)** - самый узкий экран

3. **Используйте flex-wrap для кнопок:**
   ```tsx
   <div className="flex flex-wrap gap-2 w-full sm:w-auto">
     <Button className="flex-1 sm:flex-none">Кнопка 1</Button>
     <Button className="flex-1 sm:flex-none">Кнопка 2</Button>
   </div>
   ```

4. **Для модальных окон:**
   ```tsx
   <Dialog>
     <DialogContent className="w-[95vw] max-w-full sm:w-full sm:max-w-lg">
       {/* Контент */}
     </DialogContent>
   </Dialog>
   ```

## ✅ Чеклист для каждого компонента:

При адаптации компонента проверьте:

- [ ] Используется `.responsive-container` или `.mobile-padding`
- [ ] Все тексты используют `.mobile-text-*`
- [ ] Все кнопки используют `.mobile-button-*`
- [ ] Кнопки имеют `flex-1 sm:flex-none`
- [ ] Длинные тексты обрезаются через `truncate`
- [ ] Используются `.hide-mobile` / `.show-mobile` для текстов
- [ ] Гриды используют `.mobile-grid-*`
- [ ] Input используют `.mobile-input`
- [ ] Иконки используют `.mobile-icon`
- [ ] Модальные окна имеют `w-[95vw]` на мобильных
- [ ] Нет горизонтального скролла
- [ ] Все кликабельные элементы минимум 44x44px
- [ ] Проверено на iPhone SE (375px)
