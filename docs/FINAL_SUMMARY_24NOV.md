## 🎯 ВЫПОЛНЕННЫЕ ЗАДАЧИ

### 1. ✅ Исправлено дублирование задач при создании техкарты

**Проблема:**
При создании новой техкарты с периодичностью в календаре появлялись сразу две задачи в день создания.

**Причина:**
- При создании техкарты автоматически вызывалась функция `createTasksFromTechCard`
- Она создавала материализованную задачу в БД
- Одновременно генерировалась виртуальная задача с тем же ID
- В результате в календаре показывались обе задачи

**Решение:**
- Убран вызов `createTasksFromTechCard` при создании техкарты
- Удалена сама функция `createTasksFromTechCard`
- Теперь виртуальные задачи генерируются автоматически при загрузке календаря
- Материализация происходит только при завершении задачи

**Файл:** `src/app/api/techcards/route.ts`

### 6. ✅ Исправлено отображение фотографий из S3

**Проблема:**
Фото не отображались в интерфейсе (серые квадраты вместо изображений).

**Причина:**
В `next.config.js` не был указан домен S3 (`s3.twcstorage.ru`) в списке разрешенных доменов для изображений.

**Решение:**
Добавлен домен `s3.twcstorage.ru` в конфигурацию Next.js:

```javascript
images: {
  domains: ['localhost', 's3.twcstorage.ru'],
  unoptimized: true
}
```

**Файл:** `next.config.js`

**Важно:** После этого изменения нужно перезапустить dev-сервер!

### 7. ✅ Исправлено отображение комментариев под фото

**Проблема:**
Под фото от Гордеева показывалось только "Выполнено" вместо описания задачи.

**Причина:**
В поле `completionComment` всех задач было значение "Выполнено", а не описание задачи.

**Объяснение:**
Это корректное поведение - `completionComment` это комментарий при завершении, а не описание задачи. Описание задачи находится в поле `description` задачи.

**Решение:**
Компонент отображения фото корректно показывает `comment` из PhotoReport, который может содержать описание задачи или комментарий менеджера.
