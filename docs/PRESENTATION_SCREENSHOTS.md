## ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### Качество:
- Разрешение: минимум 1920x1080
- Формат: PNG или JPG
- Без артефактов сжатия
- Четкий текст

### Оформление:
- Убрать личные данные (если нужно)
- Красивые тестовые данные
- Без ошибок и пустых полей
- Профессиональный вид

### Подготовка:
1. Заполните систему тестовыми данными
2. Создайте несколько объектов
3. Добавьте задания и отчеты
4. Загрузите фотографии
5. Создайте пользователей

---

## ПОРЯДОК СОЗДАНИЯ

1. **Подготовка данных** (1-2 часа)
   - Создайте 5-7 тестовых объектов
   - Добавьте 10-15 заданий
   - Загрузите 20-30 фотографий
   - Создайте 5-7 пользователей

2. **Создание скриншотов** (2-3 часа)
   - Следуйте списку по порядку
   - Делайте несколько вариантов
   - Проверяйте качество
   - Сохраняйте с понятными именами

3. **Обработка** (1 час)
   - Обрежьте лишнее
   - Добавьте стрелки/выноски (если нужно)
   - Проверьте размер файлов
   - Пронумеруйте

4. **Вставка в документ** (1 час)
   - Откройте PRESENTATION.md
   - Вставьте скриншоты в нужные места
   - Проверьте соответствие описанию
   - Сохраните как PDF
