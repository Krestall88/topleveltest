## КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ

### 1️⃣ Автоматические ежедневные задания
Система сама создает задания для менеджеров. Они получают уведомления в Telegram и отчитываются фото.

📸 **[СКРИНШОТ: Задание с фотоотчетом]**

### 2️⃣ Централизованное хранение фотоотчетов
Все фото в одном месте. Фильтры по дате/объекту/менеджеру. Нашли нужное фото за 30 секунд.

📸 **[СКРИНШОТ: Поиск фото по фильтрам]**

### 3️⃣ Telegram бот для клиентов
Клиенты пишут запросы в бота → попадают в систему → привязываются к объекту → менеджер получает уведомление → руководитель видит всё.

📸 **[СКРИНШОТ: Запрос клиента в боте]**

### 4️⃣ Контроль расходов по объектам
Видите в реальном времени сколько тратится на каждый объект по статьям. Лимиты, уведомления о превышении.

📸 **[СКРИНШОТ: Дашборд расходов]**

### 5️⃣ Дашборд со статистикой
Все ключевые показатели на одном экране: выполнение заданий, активность менеджеров, расходы, новые запросы.

📸 **[СКРИНШОТ: Дашборд]**

## КТО РАБОТАЕТ В СИСТЕМЕ?

- **Руководитель** — видит всё, контролирует всё
