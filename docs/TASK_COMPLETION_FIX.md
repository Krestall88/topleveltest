## 🔍 ПРИЧИНА

В компоненте `UnifiedTaskCompletionModal.tsx` было **две проблемы**:

1. Фото загружались через **несуществующий** эндпоинт `/api/upload`
2. Неправильное имя поля FormData: `files` вместо `photos`

**Было:**
```typescript
for (const photo of photos) {
  const formData = new FormData();
  formData.append('files', photo);  // ❌ Неправильное имя поля
  
  const uploadResponse = await fetch('/api/upload', {  // ❌ Неправильный эндпоинт
    method: 'POST',
    body: formData,
  });
}
```

**Должно быть:**
```typescript
const formData = new FormData();
photos.forEach(photo => {
  formData.append('photos', photo);  // ✅ Правильное имя поля
});

const uploadResponse = await fetch('/api/photos/upload', {  // ✅ Правильный эндпоинт
  method: 'POST',
  body: formData,
});
```

## 🧪 КАК ПРОТЕСТИРОВАТЬ

### Шаг 1: Перезапустить dev-сервер

```bash
# Остановить сервер (Ctrl+C)
npm run dev
```

### Шаг 2: Открыть календарь

1. Перейти на страницу календаря
2. Найти объект "Желдор Поволжья" или "Яндекс"
3. Выбрать любую задачу из списка "Текущие"

### Шаг 3: Завершить задачу с фото

1. Кликнуть на задачу
2. Откроется модальное окно завершения
3. Добавить фото (1-3 штуки)
4. Добавить комментарий (если требуется)
5. Нажать "Завершить"

**Ожидаемое поведение:**

2. ✅ Задача исчезает из списка "Текущие"
3. ✅ Задача появляется в списке "Выполнено"

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### API эндпоинт `/api/photos/upload`

**Метод:** POST  
**Content-Type:** multipart/form-data

**Параметры FormData:**
- `photos` - файлы фото (File[]) - можно добавить несколько
- `taskId` - ID задачи (string)
- `objectId` - ID объекта (string, опционально)
- `comment` - комментарий (string, опционально)

**Ответ:**
```json
{
  "photos": [
    {
      "id": "photo-id",
      "url": "https://s3.twcstorage.ru/.../photo.jpg",
      "comment": "...",
      "createdAt": "2025-11-24T..."
    }
  ],
  "message": "Фотографии успешно загружены"
}
```

### API эндпоинт `/api/tasks/unified-complete`

**Метод:** POST  
**Content-Type:** application/json

**Тело запроса:**
```json
{
  "taskId": "task-id",
  "status": "COMPLETED",
  "comment": "Комментарий",
  "photos": ["https://s3.twcstorage.ru/.../photo.jpg"]
}
```

**Ответ:**
```json
{
  "task": {
    "id": "task-id",
    "status": "COMPLETED",
    "completedAt": "2025-11-24T...",
    "completedBy": {...},
    "completionComment": "...",
    "completionPhotos": [...]
  },
  "message": "Задача успешно завершена",
  "wasVirtual": false
}
```
