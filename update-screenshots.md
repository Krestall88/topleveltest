## 📁 Где разместить скриншоты

### Вариант 1: В файловой системе (рекомендуется)
```
public/
  └── manual/
      └── screenshots/
          ├── screenshot-001.png
          ├── screenshot-002.png
          ├── ...
          └── screenshot-041.png
```

**Доступ:** `/manual/screenshots/screenshot-XXX.png`

### Вариант 2: В базе данных
Если хотите хранить в базе, создайте таблицу:
```sql
CREATE TABLE manual_screenshots (
  id SERIAL PRIMARY KEY,
  number INTEGER UNIQUE NOT NULL,
  filename VARCHAR(255) NOT NULL,
  description TEXT,
  section VARCHAR(255),
  image_data BYTEA, -- бинарные данные изображения
  created_at TIMESTAMP DEFAULT NOW()
);
```

### Вариант 3: В облачном хранилище (Supabase Storage)
```
Bucket: manual-screenshots
Path: screenshots/screenshot-XXX.png
```

## 🎯 Рекомендации

### Для продакшена используйте:
1. **Файловая система** (`public/manual/screenshots/`) - самый простой вариант
2. Скриншоты доступны напрямую через URL
3. Не нагружают базу данных
4. Легко обновлять и заменять

### В базе храните только метаданные:
```json
{
  "number": 1,
  "filename": "screenshot-001.png",
  "description": "Страница входа",
  "section": "Начало работы",
  "path": "/manual/screenshots/screenshot-001.png"
}
```
