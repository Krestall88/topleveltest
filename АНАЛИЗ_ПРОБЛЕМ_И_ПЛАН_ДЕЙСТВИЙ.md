### ❌ ПРОБЛЕМА #6: Ошибки валидации при завершении задач ✅ ИСПРАВЛЕНО

**Обнаружено по скриншотам:**
1. "Foreign key constraint violated on PhotoReport_taskId_fkey"
2. "The string did not match the expected pattern"

**Причины:**
1. **Foreign key error:** Попытка создать фотоотчет для несуществующей задачи
   - Задача может быть виртуальной (не материализованной в БД)
   - Фото загружаются РАНЬШЕ, чем задача материализуется
   - Виртуальные задачи имеют формат: `techCardId-objectId-roomId-YYYY-MM-DD`

2. **Pattern validation error:** Неправильный формат данных при валидации
   - Возможно, проблема с форматом даты или ID

**Файл с проблемой:** `src/app/api/photos/upload/route.ts`

**✅ ИСПРАВЛЕНИЕ (6 апреля 2026):**

Добавлена проверка виртуальных задач перед созданием фотоотчетов:

```typescript
// Проверяем, является ли задача виртуальной (по паттерну даты в конце ID)
const isVirtualTask = taskId && /\d{4}-\d{2}-\d{2}$/.test(taskId);

// Для виртуальных задач НЕ добавляем taskId
if (taskId && !isVirtualTask) {
  // Дополнительно проверяем существование задачи в БД
  const taskExists = await prisma.task.findUnique({
    where: { id: taskId },
    select: { id: true }
  });
  
  if (taskExists) {
    photoData.taskId = taskId;
  }
}
```

**Результат:** Фотоотчеты для виртуальных задач создаются без привязки к `taskId`, что предотвращает foreign key error. Привязка к задаче происходит позже, при материализации задачи в `/api/tasks/unified-complete`.

```typescript
import { prisma } from './prisma';

export async function withRetry<T>(
  operation: () => Promise<T>,
  maxRetries = 3,
  delay = 1000
): Promise<T> {
  let lastError: Error | null = null;
  
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await operation();
    } catch (error: any) {
      lastError = error;
      
      // Проверяем, является ли ошибка временной
      const isTemporary = 
        error.code === 'P1001' || // Can't reach database server
        error.code === 'P1002' || // Database server timeout
        error.code === 'P1008' || // Operations timed out
        error.message?.includes('ECONNREFUSED') ||
        error.message?.includes('ETIMEDOUT');
      
      if (!isTemporary || i === maxRetries - 1) {
        throw error;
      }
      
      console.log(`⚠️ Retry ${i + 1}/${maxRetries} after ${delay}ms`);
      await new Promise(resolve => setTimeout(resolve, delay * (i + 1)));
    }
  }
  
  throw lastError;
}

export async function checkDatabaseConnection(): Promise<boolean> {
  try {
    await prisma.$queryRaw`SELECT 1`;
    return true;
  } catch (error) {
    console.error('❌ Database connection failed:', error);
    return false;
  }
}
```
